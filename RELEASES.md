# Face Mouse Pro — Release Roadmap & Versioning Strategy

## Semantic Versioning Guidelines (`MAJOR.MINOR.PATCH`)

- **MAJOR (`X.0.0`)**: Breaking architectural changes, major UI overhaul, or new AI backends.
- **MINOR (`1.X.0`)**: New gestures, additional platform support (macOS/Linux), or UI features.
- **PATCH (`1.0.X`)**: Bug fixes, calibration optimizations, or performance patches.

---

## Release Roadmap

### 🚀 v1.0.0 — Production Release (Current)
- Complete face tracking, EAR/MAR gesture engine, One-Euro smoothing, and CustomTkinter settings panel.
- Standalone Windows x64 executable bundle.

### 🌟 v1.1.0 — Enhanced Modalities (Planned)
- Eyebrow raise gesture for middle-click / app switching.
- Head roll tilt gesture for horizontal scrolling.
- Multi-monitor screen selection support.

### 🔮 v2.0.0 — Next-Gen AI & Cross-Platform (Future)
- Iris gaze-tracking fusion.
- Cross-platform packaging for macOS (Metal/CoreVideo) and Linux (X11/Wayland).
